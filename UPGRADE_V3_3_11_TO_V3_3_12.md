# Upgrade v3.3.11 → v3.3.12

1. Keep the bot PARADO.
2. Pull main and verify VERSION=3.3.12.
3. Restart START_BOT.bat and Ctrl+F5 the dashboard.
4. On Config click Diagnosticar red BEFORE generating another OAuth code.
5. If result is EDGE_ROUTE_BLOCKED, change public network/IP (for example phone hotspot).
6. Run Diagnosticar red again.
7. Only when ROUTE_REACHABLE, click Abrir Schwab OAuth and use a brand-new callback URL/code.
8. Run Test and broker read-only reconciliation before REAL.

Do not rotate Client ID/Secret merely because an HTML Access Denied page appears.
