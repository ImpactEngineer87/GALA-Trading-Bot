## Changes applied

- Check broker positions periodically even when a local protective STOP still
  appears WORKING. A cached flat hint is confirmed by a fresh position GET
  before any protection is canceled. One cached broker snapshot is shared across
  tickers to limit extra API traffic.
- Verify an exact external closing fill regardless of broker tag. The tag cannot
  establish who submitted an order. Entry identity, side, prices, quantities,
  unique external fill and net share balance are still required. Audited GALA
  orders cannot be mislabeled as manual fills.
- When Schwab confirms flat before fill evidence arrives, retain the local
  position and retry automatically on the same engine. A separate durable queue
  preserves the unresolved evidence; no fabricated close/price/training label is
  written. Verified accounting clears that queue. A crash or unresolved evidence
  can still require recovery; unreadable state and unknown daily loss remain
  entry holds. This upgrade does not remove the daily loss guard.
- Missing/corrupt or newly added ticker records default to PAPER. Training/PASS
  cannot implicitly select REAL. Existing valid saved selections are preserved.
- The AI table displays saved execution mode, inference model tier and its actual
  training date. PASS explicitly says it does not activate REAL. Model snapshots
  also expose artifact modification timestamps and byte identities.
- Remove the five-minute fallback from the one-minute signal calculation. Missing
  one-minute data cannot silently change the strategy timeframe.
- Persist the exact closed-bar OHLCV, history window hash and strategy settings
  for future comparisons. `/api/strategy/evidence` reads the latest records;
  the audit ledger retains STRATEGY_CANDLE_EVALUATED events. New model evaluations
  retain a dataset hash. These receipts improve traceability; they do not prove
  parity with an external chart whose study inputs/candles are unavailable.
- `scripts/audit_ai_runtime.py` produces read-only per-ticker model dates,
  identities, saved routing and training event receipts without broker calls.
