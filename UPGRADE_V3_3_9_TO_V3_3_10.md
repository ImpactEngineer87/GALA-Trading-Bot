# Upgrade v3.3.9 → v3.3.10

## Purpose
Fix the **Todos** option in the signal-learning ticker selector.

## Steps
1. Keep the bot **PARADO**.
2. Update the source to v3.3.10.
3. Restart `START_BOT.bat`.
4. Refresh the browser with `Ctrl+F5`.
5. Open **Señales → Visibilidad · Aprendizaje de señales**.
6. Select META (or another ticker), then select **Todos**.
7. Confirm the summary and recent-observation tables return to all tickers.

No configuration, model, data, OAuth, or trading-state migration is required.
